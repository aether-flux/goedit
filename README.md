# goedit

A Go port of the `kilo` text editor tutorial, built as my first Go project.

## Status

#### Included

- Raw terminal mode
- Scrolling
- File open/create/save
- Search (supports multiple matches per line)

#### Incomplete

- Syntax highlighting (minimal numbers-only for now)

## Usage

```bash
go run . [filename]
```

## Notes

Built to learn Go and its standards, as well as terminal mechanisms and how to build a text editor from scratch.
